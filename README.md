# Java Programming N ☕

A collection of **Java programming practice programs** covering fundamental concepts such as variables, arrays, methods, patterns, and basic problem-solving.

This repository is intended for beginners who are learning Java and want to practice programming concepts through simple examples.

## 📚 Topics Covered

* Java Variables
* Arrays
* Two-Dimensional Arrays
* Methods
* Array Reversal
* Even and Odd Numbers
* Patterns
* Triangles
* Diamonds
* Square Borders
* Basic Java Programs

## 📂 Programs

| File                      | Description                                 |
| ------------------------- | ------------------------------------------- |
| `Hello.java`              | Basic Java Hello World program              |
| `variables.java`          | Examples of Java variables                  |
| `arrays.java`             | Basic array operations                      |
| `demoarray.java`          | Array practice                              |

## 🛠️ Requirements

To run these programs, you need:

* **Java Development Kit (JDK)**
* A Java-compatible IDE or text editor
* Basic knowledge of Java syntax

Check your Java installation:

```bash
java -version
javac -version
```

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/chaycom/Java-Programming-N.git
```

Move into the project directory:

```bash
cd Java-Programming-N
```

Compile a Java program:

```bash
javac Hello.java
```

Run it:

```bash
java Hello
```

You can replace `Hello.java` with any of the Java files in the repository.
